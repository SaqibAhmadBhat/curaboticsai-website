## Google Search Console Setup Steps

1. **Go to** [Google Search Console](https://search.google.com/search-console/about)
2. **Add property** → Choose "URL prefix" → Enter `https://curaboticsai.com`
3. **Verify ownership** using one of:
   - HTML tag method (add `<meta name="google-site-verification" content="YOUR_CODE" />` to layout.tsx `verification.google`)
   - DNS TXT record (recommended for domain-level verification)
   - HTML file upload to `public/` directory
4. **Submit sitemap** → Go to Sitemaps → Enter `sitemap.xml` → Submit
5. **Request indexing** for all key pages:
   - `https://curaboticsai.com/`
   - `https://curaboticsai.com/about`
   - `https://curaboticsai.com/services`
   - `https://curaboticsai.com/projects`
   - `https://curaboticsai.com/careers`
   - `https://curaboticsai.com/contact`
6. **Monitor** Coverage report weekly for crawl errors
7. **Set up** Search Appearance → Structured Data report
8. **Enable** email alerts for critical issues

### Additionally:
- Set up **Bing Webmaster Tools** at [bing.com/webmasters](https://www.bing.com/webmasters)
- Submit sitemap to Bing as well
- Once verified, add the verification codes to `layout.tsx` metadata `verification` field
